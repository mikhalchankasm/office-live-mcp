## Статус

**Активно дорабатывается.** Релизы 0.x — инструменты и установщик проверены на настоящих Excel и Word, но проект
продолжает развиваться. Power Query и Power Pivot/DAX запланированы на следующие релизы. Замечания и issues приветствуются.

## Установка, обновление, удаление

**Что нужно:** Windows 10/11 (64-бит) и настольные Excel и/или Word. Python, git, winget и права администратора не нужны.

| Шаг | Что сделать |
|:---:|---|
| **1** | Скачайте **установщик Windows (файл с окончанием `-setup.exe`)** со страницы [**последнего релиза**](https://github.com/mikhalchankasm/office-live-mcp/releases/latest). |
| **2** | Запустите его: **Далее → Далее → Готово**. Мастер проверит Office и установит программу. При первой установке найденные агенты уже отмечены; оставьте отметки, чтобы подключить всех найденных. Выберите доступ: **полный** или **только чтение**. |
| **3** | **Перезапустите агента** и попросите: *«покажи, какие книги открыты в Excel»*. |

### Обновление

| Шаг | Что сделать |
|:---:|---|
| **1** | Скачайте новый **setup.exe** со страницы [Releases](https://github.com/mikhalchankasm/office-live-mcp/releases/latest). |
| **2** | Запустите поверх существующей установки. Подключённые агенты сохраняют настройки; выбор доступа применяется только к добавляемым. По запросу мастера закройте агентов, использующих сервер. Снятая отметка отключает учтённые регистрации агента. |
| **3** | Перезапустите агента. |

**Удаление:** **Параметры → Приложения → Office Live MCP → Удалить**. Состояние, журналы и резервные копии конфигураций остаются.

Программа находится в `%LOCALAPPDATA%\Programs\office-live-mcp\app`. В меню «Пуск → Office Live MCP» есть ярлыки
**«Подключить к агентам»** и **«Проверка (doctor)»**. VS Code и проектные конфигурации подключаются через консольный ярлык.

### Тихая установка

Для автоматического подключения всех найденных поддерживаемых агентов передайте скачанному установщику `/CLIENTS=detected`.
Выберите `/ACCESS=full` для редактирования или `/ACCESS=readonly` для чтения; этот выбор применяется к новым подключениям.
Параметры тихой установки — в [справочнике для администраторов](GUIDE.ru.md#тихая-установка-для-администраторов).

Без `/CLIENTS` тихая установка не добавляет агентов, а обновление сохраняет существующие регистрации.
Есть `setup --config PATH`, `--scope project --project DIR` и
`setup --remove --clients zcode`. Учёт всех областей, защита чужих записей, откат и примеры —
[в руководстве](GUIDE.ru.md#установка-подключения-и-обновление).
Запись настроек проверяется чтением обратно; загрузка сервера клиентом требует его перезапуска.
Portable-режим пока в планах; установка для всех пользователей не поддерживается.

Exe пока не подписан сертификатом: SmartScreen может предупредить (*Подробнее* → *Выполнить в любом случае*), а Smart App
Control или корпоративный антивирус — заблокировать запуск. Из исходников: `install.cmd` в клоне репозитория или
`pip install .` и `python -m office_live setup` — см. [руководство](GUIDE.ru.md).

### Для администраторов: запасной ZIP

В релизе также есть **`office-live-mcp-<версия>-win64.zip`**. Распакуйте архив целиком и запустите `install.cmd`
(или `install.cmd --yes --clients none`). Обновление использует запомненную папку; для своей папки есть `--target`.
Установки 0.4.x из ZIP можно обновить setup.exe без изменения пути `app\office-live-mcp.exe` в конфигах агентов.
После перехода на setup.exe обновляйте программу новым setup.exe.

## Что умеет

123 инструмента, включая опциональный Python, в наборах, которые можно включать и выключать (`OFFICE_LIVE_TOOLSETS`); каталог —
[TOOLS.md](TOOLS.md).

| Набор | Главное |
|---|---|
| Excel | чтение и запись диапазонов, **сравнение по позиции или ключу**, **очистка текстов, даты по явному формату и разбиение столбца с предпросмотром/отменой**, **трассировка формул с указанием неполноты**, **защита листа/книги, подбор параметра, промежуточные итоги и спарклайны**, формулы (A1, R1C1, динамические массивы), оформление, условное форматирование, проверка данных, сортировка и фильтр, скрытие и группировка строк, имена, умные таблицы, **сводные таблицы с фильтрами, срезами и временными шкалами**, диаграммы, профиль данных, поиск проблем, чертёж листа, снимок диапазона в PNG |
| Word | **предпросмотр точечной правки с исправлениями и ветки комментариев**, **вставка сохранённых документов, ограничения редактирования, таблица ↔ текст**, **сравнение документов в новый документ с исправлениями**, **сортировка таблиц по трём ключам с отменой**, структура, чтение страницами, точная замена, вставка в закладку или рядом с таблицей, стили, списки, таблицы, колонтитулы, оглавление, комментарии, исправления, сноски, снимок страницы в PNG, шаблоны с `{{метками}}` |
| Мосты | таблица Word → Excel (числа становятся числами, `007` остаётся текстом), диапазон и диаграмма Excel → Word, слияние Excel → Word/PDF с планом в readonly, разбор файла без открытия |
| История | журнал изменений по каждому документу, необязательный лист «Лог» в Excel, `office_undo` для правок агента |

## Безопасность

- **Только чтение** (`OFFICE_LIVE_MODE=readonly`): пишущие инструменты не регистрируются, у многоактных остаются только
  действия чтения. Единственный читающий инструмент с побочным эффектом — снимок диапазона (PNG): временная диаграмма на
  листе помечает книгу как изменённую.
- **Разрешённые папки** (`OFFICE_LIVE_ALLOWED_DIRS`): файлы вне них агенту не видны; ничего не сохраняется само, существующие
  файлы не перезаписываются без `overwrite=true`.
- Книги с **автосохранением** (OneDrive/SharePoint) не меняются; на время правок агента события Excel и макросы выключены.
- **Журнал и отмена**: каждая правка записывается в журнал документа; `office_undo` отменяет шаги агента (через историю Word,
  в Excel — по снимкам) и отказывает, если вы потом правили то же место, пока не передан `force=true`.
- Необязательный журнал аудита (`OFFICE_LIVE_AUDIT_LOG`) и строгий выбор файла (`OFFICE_LIVE_STRICT_TARGET`).
- Пароли защиты маскируются в журналах, ошибках и истории. Операция с паролем создаёт барьер отмены; без пароля отмена возвращает флаги защиты и свойства Locked.

Сервер работает локально и не открывает портов. Прочитанное агентом отправляется поставщику его модели — для конфиденциальных
файлов ограничьте папки. Подробности и ограничения: [руководство](GUIDE.ru.md) · [SECURITY.md](../SECURITY.md).

Работа в открытом документе, ссылки на ячейки, сводные таблицы, исправления Word и общий контекст Excel и Word есть и
у этих ассистентов. Office Live MCP — для тех, кто хочет, чтобы в Office работал **свой агент** (Claude Code, Cursor,
Codex CLI, ZCode, VS Code…), с ограничениями на стороне сервера, которые задаёте вы.

### MCP-серверы для Office

| Проект | Как работает | Документы | По его README |
|---|---|---|---|
| **Office Live MCP** | COM к запущенным Excel и Word | уже открытые файлы | мосты Word↔Excel, журнал, отмена поддерживаемых действий, режим только чтения, разрешённые папки |

| [negokaz/excel-mcp-server](https://github.com/negokaz/excel-mcp-server) (MIT) | файлы; в Windows — правка открытых книг | файлы; открытые книги в Windows | 7 инструментов в README; снимок экрана в Windows |
| [GongRzhe/Office-Word-MCP-Server](https://github.com/GongRzhe/Office-Word-MCP-Server) (MIT) | файлы через python-docx | файлы на диске | репозиторий архивирован (только чтение) |
| [OfficeMCP/OfficeMCP](https://github.com/OfficeMCP/OfficeMCP) | COM через общий инструмент `RunPython` | запущенные приложения Office | много приложений Office; агент выполняет произвольный Python; файла лицензии нет |

Для серверных и кроссплатформенных сценариев лучше подходят серверы, работающие с файлами; COM-серверам нужны Windows
и настольный Office.

## Разработка

```bat
python -m venv .venv && .venv\Scripts\pip install -r requirements.txt pytest ruff
.venv\Scripts\python -m pytest tests -q          :: юнит-тесты, Office не нужен
set OFFICE_LIVE_LIVE_TESTS=1 && .venv\Scripts\python -m pytest tests\live -m smoke -q   :: быстрый живой набор, ~4 мин (настоящие Excel и Word)
set OFFICE_LIVE_LIVE_TESTS=1 && .venv\Scripts\python -m pytest tests\live -q            :: полный живой набор, ~12 мин, перед релизом
.venv\Scripts\python packaging\build.py          :: собрать setup.exe + ZIP (нужны pyinstaller и Inno Setup 6.7+)
```

Устройство, особенности COM и все настройки — [GUIDE.ru.md](GUIDE.ru.md). Изменения — [CHANGELOG.md](../CHANGELOG.md).
