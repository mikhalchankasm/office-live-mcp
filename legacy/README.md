# legacy

Файлы первой версии (0.1), вынесенные из корня. Не используются, оставлены для истории.

| Файл | Почему не используется |
|---|---|
| `close_scratch.py` | **Опасен:** закрывает без сохранения любую книгу с именем «Книга…» (в том числе новую несохранённую книгу пользователя) и делает `Quit()` для всего Word. Новые тесты закрывают только созданные ими файлы. |
| `launch_scratch.py`, `stdio_drive.py` | Заменены живым набором `tests/live/test_live.py` (с настоящими проверками, а не печатью). |
| `test_live.py` | Вызывал инструменты в том же процессе, что рвёт COM-апартаменты (см. README, «Особенности COM»); к тому же закрывал Word целиком. |
| `smoke.jsonl`, `smoke.err`, `scratch-test.*` | Артефакты прогонов (в `smoke.jsonl` — реальные пути ваших файлов). |
